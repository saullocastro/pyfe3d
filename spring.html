Spring - 3D spring element with constant stiffnesses (pyfe3d.spring)#

Defines the two-node element Spring, with six degrees-of-freedom per node and a constant stiffness for each of them, its probe SpringProbe and SpringData, which gives the number of sparse entries per element of each structural matrix.

class pyfe3d.spring.Spring#

Spring 3D beam element with constant stiffnesses

Note

The default behaviour assumes that the local coordinate system is aligned with the global coordinate system

The constructor stores p in probe, sets eid, n1, n2, c1 and c2 to -1, sets the init_k_* positions, the stiffnesses and vxyi, vxyj, vxyk to 0, and sets the rotation matrix to the identity. update_KC0() and update_probe_finte() read the stiffnesses and the rotation matrix; update_probe_finte() also reads probe.ue, updated by update_probe_ue(). The element has no length, and the nodal coordinates are not used.

pSpringProbe object

Probe of the element, stored in probe. It can be shared with other elements.

kxe, kye, kze: double

Translational stiffnesses in the element coordinate system, force per unit length.

Rotational stiffnesses in the element coordinate system, moment per unit rotation.

r11, r12, r13, r21, r22, r23, r31, r32, r33double

Entries \(T_{ij}\) of the transformation matrix \(\boldsymbol{T}_{3\times 3}\) from element to global coordinates, whose columns are the element axes. By default it assumes that the element is aligned with the global coordinate system. Dimensionless.

vxyi, vxyj, vxykdouble

Components of a vector on the \(XY\) plane of the element coordinate system, defined using global coordinates. Only the direction of the vector is used.

n1, n2int

Node identification number.

init_k_KC0, init_k_KG, init_k_Mint

Position in the arrays storing the sparse data for the structural matrices, where the entries of this element start, see SpringData for their number.

Notes

The strain energy of the element is

\[U = \frac{1}{2} \sum_{i=1}^{6} k_i \left( {u_e}_{i+6} - {u_e}_{i} \right)^2\]

where \(k_1, ..., k_6\) are kxe, kye, kze, krxe, krye and krze, and ue are the displacements in the element coordinate system, in the order of SpringProbe. Each stiffness connects only the same degree-of-freedom of the two nodes, without coupling between translations and rotations, such that the internal forces are finte = [K_e] ue with

\[\begin{split}\boldsymbol{K}_e = \begin{bmatrix} [k] & -[k] \\ -[k] & [k] \end{bmatrix}, \qquad [k] = \mathrm{diag}(k_1, ..., k_6)\end{split}\]

transformed to global coordinates with the transformation matrix of the element, \(\boldsymbol{K} = \boldsymbol{T} \boldsymbol{K}_e \boldsymbol{T}^\top\), where \(\boldsymbol{T}\) is block diagonal with four copies of the matrix \(\boldsymbol{T}_{3\times 3}\) of the entries \(T_{ij}\) stored in r11, ..., r33, whose columns are the element axes.

A rigid translation and equal rotations of the two nodes give no internal forces. Since the nodal coordinates are not used, a rigid rotation \(\boldsymbol{\theta}\) of two nodes at different positions \(\boldsymbol{p}_1\) and \(\boldsymbol{p}_2\) gives the relative translation \(\boldsymbol{\theta} \times (\boldsymbol{p}_2 - \boldsymbol{p}_1)\), normal to the line of the nodes, which loads the translational stiffnesses in that direction: with the element \(x\) axis along the line of the nodes, kye and kze. These properties are verified in tests/test_spring.py.

update_KC0(self, long[: :1] KC0r, long[: :1] KC0c, double[: :1] KC0v, int update_KC0v_only=0) → void#

Update sparse vectors for linear constitutive stiffness matrix KC0

The 72 entries of the matrix of the element, in global coordinates, are written at the positions init_k_KC0 to init_k_KC0 + 71: the row and column indices, built from c1 and c2, are stored in KC0r and KC0c, and the values are added to those already in KC0v. The matrix is computed from the rotation matrix and the stiffnesses kxe, kye, kze, krxe, krye and krze. The rotation matrix must be updated before, when the element is not aligned with the global coordinate system, see update_rotation_matrix().

Parameters:
KC0rnp.array

Array to store row positions of sparse values. 1-D array of integers of the C type long, of size at least init_k_KC0 + 72.

KC0cnp.array

Array to store column positions of sparse values. Same type and size as KC0r.

KC0vnp.array

Array to store sparse values. 1-D array of floats of size at least init_k_KC0 + 72.

update_KC0v_onlyint, optional

The default 0 means that the row and column indices KC0r and KC0c should also be updated. Any other value will only update the stiffness matrix values KC0v.

update_fint(self, double[: :1] fint) → void#

Update the internal force vector

Calls update_probe_finte(), transforms the forces and moments of probe.finte to global coordinates with the rotation matrix and adds them to fint at the positions c1 to c1 + 5 and c2 to c2 + 5. The displacements probe.ue must be updated before, see update_probe_ue().

Parameters:
fintnp.array

Array that is updated in place with the internal forces. The internal forces stored in fint are calculated in global coordinates. Method update_probe_finte() is called to update the parameter finte of the SpringProbe with the internal forces in local coordinates. 1-D array of size 6*M, for \(M\) nodes in the model.

update_probe_finte(self) → void#

Update the internal force vector of the probe

The attribute finte is updated with the SpringProbe the internal forces in local coordinates. While using this function, mind that the probe can be shared amongst more than one finite element, depending how you defined them, meaning that the probe will always safe the values from the last udpate.

Note

The finte attribute of object SpringProbe is updated, accessible using .probe.finte.

The 12 values of finte are overwritten. They are computed from the stiffnesses kxe, kye, kze, krxe, krye and krze and from the displacements probe.ue, which must be updated before, see update_probe_ue().

update_probe_ue(self, double[: :1] u) → void#

Update the local displacement vector of the probe of the element

Note

The ue attribute of object SpringProbe is updated, accessible using .probe.ue.

The translations and rotations of the two nodes, read from u at the positions c1 to c1 + 5 and c2 to c2 + 5, are transformed to the element coordinate system with the transpose \(\boldsymbol{T}_{3\times 3}^\top\) of the transformation matrix, which must be updated before, see update_rotation_matrix().

Parameters:
uarray-like

Array with global displacements, for a total of \(M\) nodes in the model, this array will be arranged as: \(u_1, v_1, w_1, {r_x}_1, {r_y}_1, {r_z}_1, u_2, v_2, w_2, {r_x}_2, {r_y}_2, {r_z}_2, ..., u_M, v_M, w_M, {r_x}_M, {r_y}_M, {r_z}_M\). Translations of dimension length and rotations, 1-D array of size 6*M.

update_rotation_matrix(self, double xi, double xj, double xk, double vxyi, double vxyj, double vxyk) → void#

Update the rotation matrix of the element

Attributes r11,r12,r13,r21,r22,r23,r31,r32,r33 are updated, with the entries \(T_{ij}\) of the transformation matrix \(\boldsymbol{T}_{3\times 3}\) from element to global coordinates, whose columns are the element axes.

The element coordinate system is determined, identifying the \(ijk\) components of each axis: \({x_e}_i, {x_e}_j, {x_e}_k\); \({y_e}_i, {y_e}_j, {y_e}_k\); \({z_e}_i, {z_e}_j, {z_e}_k\).

The element \(x\) axis is (xi, xj, xk), the \(z\) axis is normal to the \(x\) axis and to the vector (vxyi, vxyj, vxyk), the \(y\) axis completes the right-handed system, and the three axes are normalized. The element attributes vxyi, vxyj and vxyk are also updated.

Parameters:
xi, xj, xkdouble

Components, in global coordinates, of the element x-axis. Only the direction of the vector is used.

vxyi, vxyj, vxykdouble

Components, in global coordinates, of a vector on the \(XY\) plane of the element coordinate system. Only the direction of the vector is used. A vector parallel to the element x-axis gives a null \(z\) axis and a rotation matrix with nan entries.

class pyfe3d.spring.SpringData#

Used to allocate memory for the sparse matrices.

Each attribute is the number of entries that one Spring element writes in the arrays of rows, columns and values of a sparse matrix, at the consecutive positions that start at its init_k_KC0, init_k_KG or init_k_M. The constructor takes no argument and sets the values below.

Attributes:
KC0_SPARSE_SIZE,int

KC0_SPARSE_SIZE = 72, written by Spring.update_KC0().

KG_SPARSE_SIZE,int

KG_SPARSE_SIZE = 0, the element has no geometric stiffness matrix.

M_SPARSE_SIZE,int

M_SPARSE_SIZE = 0, the element has no mass matrix.

class pyfe3d.spring.SpringProbe#

Probe used for local coordinates, local displacements, local stresses etc

The idea behind using a probe is to avoid allocating larger memory buffers per finite element. The memory buffers are allocated per probe, and one probe can be shared amongst many finite elements, with the information being updated and retrieved on demand.

Note

The probe can be shared amongst more than one finite element, depending on how you defined them. Mind that the probe will always safe the values from the last udpate.

The constructor takes no argument and allocates the arrays below, filled with zeros.

Attributes:
xe,array-like

Array of size NUM_NODES*DOF//2=6 containing the nodal coordinates in the element coordinate system, in the following order \({x_e}_1, {y_e}_1, {z_e}_1, {x_e}_2, {y_e}_2, {z_e}_2\). Dimension length. Not updated by the methods of Spring.

ue,array-like

Array of size NUM_NODES*DOF=12 containing the element displacements in the following order \({u_e}_1, {v_e}_1, {w_e}_1, {{r_x}_e}_1, {{r_y}_e}_1, {{r_z}_e}_1, {u_e}_2, {v_e}_2, {w_e}_2, {{r_x}_e}_2, {{r_y}_e}_2, {{r_z}_e}_2\). Translations of dimension length and rotations. Updated by Spring.update_probe_ue().

finte,array-like

Array of size NUM_NODES*DOF=12 containing the element internal forces corresponding to the degrees-of-freedom described by ue, forces and moments. Updated by Spring.update_probe_finte().
