Calls to the callables of the non-linear solvers (pyfe3d.solver.callbacks)#

The callables of Analysis, calc_fext, calc_fint, calc_kC and calc_kG, may depend on the load factor and on the configuration through optional keyword arguments, which are passed only when the callable declares them explicitly in its signature (a **kwargs does not count), such that the simplest callables are called with the minimum set of arguments:

  • inc: the current load factor, passed to calc_fint, calc_kC and calc_kG. It allows configuration-dependent loads, e.g. follower pressures, whose configuration-dependent part enters calc_fint and whose load stiffness enters calc_kC or calc_kG, both scaled by the load factor.

  • c: the current configuration, passed to calc_fext, which must then return the load vector of that configuration for a unit load factor. The arc-length solvers use it in the predictor and in the constraint instead of the constant reference vector calc_fext(inc=1.).

  • lbd: the current load factor, passed to calc_fext together with c, for a load vector that depends on the load factor as well, e.g. prescribed displacements imposed exactly as linear constraints. The keyword inc keeps its meaning, the factor that multiplies the returned vector, and the solvers keep calling calc_fext(inc=1., ...). When calc_fext declares lbd:

    • the arc-length solvers pass lbd with c in the predictor and in the constraint;

    • the arc-length solvers scale the displacements with the linear solution of the load vector at c = 0, lbd = 0, instead of the linear solution of the reference vector calc_fext(inc=1.), and the Newton-Raphson solver uses this linear solution as the predictor of its first increment;

    • the load factor times the load vector is an additional reference of the convergence criteria, see convergence;

    • calc_fext(c=c, lbd=lbd) is called at the configurations where the tangent stiffness matrix is updated, right after calc_kC and calc_kG at the same c and load factor, such that the callables may share their computations, and the last load vector evaluated is the reference of the convergence checks until the next update.

    lbd is never passed by the linear static analysis, Analysis.static(NLgeom=False).

The prescribed displacements of Analysis with bu and uk are implemented with these keyword arguments, see FreeDofs.

Notes#

With inc, the residual is

\[\boldsymbol{R}(\boldsymbol{c}, \lambda) = \boldsymbol{F}_{int}(\boldsymbol{c}, \lambda) - \lambda \boldsymbol{F}_{ext}\]

with calc_kC + calc_kG its exact Jacobian \(\partial \boldsymbol{R}/\partial \boldsymbol{c}\).

With c, calc_fext(inc=1., c=c) is \(-\partial \boldsymbol{R}/\partial \lambda\) at \(c\).

With lbd, prescribed displacements imposed exactly as linear constraints \(\boldsymbol{c} = \boldsymbol{Z} \boldsymbol{c}_r + \boldsymbol{c}_{p0} + \lambda \boldsymbol{c}_{p1}\) give the reduced residual

\[\boldsymbol{R}_r(\boldsymbol{c}_r, \lambda) = \boldsymbol{Z}^\top \left( \boldsymbol{F}_{int}(\boldsymbol{Z} \boldsymbol{c}_r + \boldsymbol{c}_{p0} + \lambda \boldsymbol{c}_{p1}) - \lambda \boldsymbol{F}_{ext} \right)\]

which has \(-\partial \boldsymbol{R}_r/\partial \lambda = \boldsymbol{Z}^\top(\boldsymbol{F}_{ext} - \boldsymbol{K}_T \boldsymbol{c}_{p1})\), with \(\boldsymbol{K}_T\) evaluated at the current configuration and load factor, the vector that calc_fext(inc=1., c=c, lbd=lbd) must return. Under a prescribed displacement alone the reference vector and the reduced internal force vector both vanish at equilibrium, and the convergence criteria use \(-\lambda \, \partial \boldsymbol{R}/\partial \lambda\) as an additional reference; the displacements of the arc-length solvers are scaled with the linear solution of \(-\partial \boldsymbol{R}/\partial \lambda\) at \(\boldsymbol{c} = \boldsymbol{0}, \lambda = 0\), since the reference vector calc_fext(inc=1.) may then be null.

pyfe3d.solver.callbacks.accepts_kwarg(func, name)#

Tell whether func declares the keyword argument name

The argument is declared when it is a named parameter of the signature, positional-or-keyword or keyword-only; a **kwargs does not count. A callable whose signature cannot be read by inspect.signature() does not declare it.

Parameters:
funccallable

Function or method to inspect.

namestr

Name of the keyword argument.

Returns:
acceptsbool

True when func has a parameter name that can be passed by keyword.

See also

calc_fint, calc_kT, calc_load_vector

calls that depend on it.

pyfe3d.solver.callbacks.calc_fint(pb, c, lbd)#

pb.calc_fint at c, with inc=lbd when accepted

Calls pb.calc_fint(c=c, silent=True), adding inc=lbd only when pb.calc_fint declares inc, see accepts_kwarg().

Parameters:
pbobject

Object providing calc_fint, an Analysis or a FreeDofs.

cnp.ndarray

Configuration, the vector of the degrees-of-freedom.

lbdfloat

Current load factor, dimensionless, passed as inc.

Returns:
fintnp.ndarray

The internal force vector returned by pb.calc_fint.

pyfe3d.solver.callbacks.calc_kT(pb, c, lbd)#

Tangent stiffness matrix calc_kC + calc_kG at c

Calls pb.calc_kC(c=c, NLgeom=True, silent=True) and pb.calc_kG(c=c, NLgeom=True, silent=True), each with inc=lbd only when it declares inc, see accepts_kwarg(), and returns their sum.

Parameters:
pbobject

Object providing calc_kC and calc_kG, an Analysis or a FreeDofs.

cnp.ndarray

Configuration, the vector of the degrees-of-freedom.

lbdfloat

Current load factor, dimensionless, passed as inc.

Returns:
kTsparse_matrix or np.ndarray

The sum of the matrices returned by pb.calc_kC and pb.calc_kG, of the type given by them.

pyfe3d.solver.callbacks.calc_load_vector(pb, c, fext, lbd=None)#

Load vector, minus the derivative of the residual with respect to the load factor

Returns the load vector q given by pb.calc_fext for a unit load factor at the configuration c and the load factor lbd, used by the solvers in the predictors, in the arc-length constraint and in the convergence criteria. With prescribed displacements, q is not their reaction force: it has the size of the reduced problem and acts on the free degrees-of-freedom.

pb.calc_fext is called with inc=1. and only with the keyword arguments that it declares:

  • c=c, when it declares c;

  • lbd=lbd, when it declares lbd and lbd is not None.

When none of them is passed, q is the constant reference vector, and fext is returned without calling pb.calc_fext.

Parameters:
pbobject

Object providing calc_fext.

cnp.ndarray

Configuration.

fextnp.ndarray

Reference vector pb.calc_fext(inc=1.).

lbdfloat or None, optional

Load factor, dimensionless. Default None.

Returns:
qnp.ndarray

\(-\partial \boldsymbol{R}/\partial \lambda\), of the size of c.

Notes

\(\boldsymbol{q} = -\partial \boldsymbol{R}/\partial \lambda\) is the external load vector only for loads that do not depend on the configuration; with prescribed displacements imposed exactly it also contains \(-\boldsymbol{Z}^\top \boldsymbol{K}_T \boldsymbol{c}_{p1}\), see the module documentation, i.e. the out-of-balance force produced by a unit increment of the load factor at the current configuration with the free degrees-of-freedom held fixed. The reaction is a quantity of the full problem, \(\boldsymbol{F}_{int}(\boldsymbol{c}) - \lambda \boldsymbol{F}_{ext}\) at the constrained degrees-of-freedom.

pbobject

Object providing calc_fext.

Returns:
dependentbool
