General-purpose finite element solver - pyfe3d#

The pyfe3d module is a general-purpose finite element solver for structural analysis and optimization based on Python and Cython. The main principles guiding the development of pyfe3d are: simplicity, efficiency and compatibility. The aimed level of compatibility allows one to run this solver in any platform, including the Google Colab environment.

With pyfe3d you can build models of:

  • Shells, with the quadrilaterals Quad4 and Quad4R and the triangles Tria3DSG and Tria3R, and laminated or isotropic properties, ShellProp

  • Beams, with the Timoshenko elements BeamC and BeamLR, trusses, Truss, and springs, Spring

all with six degrees of freedom per node, whose element matrices are written into sparse arrays: the linear constitutive stiffness matrix, the non-linear constitutive and geometric stiffness matrices, the mass matrix and, for the quadrilaterals, the aerodynamic matrices of the piston theory. With the solvers of pyfe3d.solver you can run:

  • Linear static analyses, \(\boldsymbol{K}_{C0} \boldsymbol{u} = \boldsymbol{f}\), with solve() or Analysis

  • Linear buckling analyses, \((\boldsymbol{K}_{C0} + \lambda \boldsymbol{K}_G) \boldsymbol{u} = \boldsymbol{0}\), with linear_buckling()

  • Natural frequency analyses, \((\boldsymbol{K}_{C0} - \omega_n^2 \boldsymbol{M}) \boldsymbol{u} = \boldsymbol{0}\), with natural_frequency(), and complex frequencies of damped systems, \((\lambda^2 \boldsymbol{M} + \lambda \boldsymbol{C} + \boldsymbol{K}) \boldsymbol{u} = \boldsymbol{0}\), with complex_frequency()

  • Geometrically non-linear static analyses with Analysis, using the Newton-Raphson method or the arc-length methods of Riks and of Crisfield, with Crisfield’s convergence criterion, configuration-dependent loads and prescribed displacements

The eigenvalue solvers verify their results and use a dense solver only as a last resort, see Linear buckling and natural frequencies.

Installing pyfe3d#

Install the distributed binaries by simply doing:

python -m pip install pyfe3d

or, from the source code, with a C++ compiler:

python -m pip install .

See Installation and building for building in place, running the tests and building this documentation, and Repository structure for the layout of the repository.
