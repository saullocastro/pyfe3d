API reference
=============

The element classes, their ``Data`` and ``Probe`` classes, the classes of
the co-rotational layer for large rotations, e.g. ``CorotationalModel``,
and the constants ``DOF``, ``INT`` and ``DOUBLE`` are available directly
from the ``pyfe3d`` namespace, and the solvers from ``pyfe3d.solver``; the
finite-rotation utilities of the co-rotational layer, e.g. ``expso3``, are
imported from ``pyfe3d.corotational``, as are its classes:
